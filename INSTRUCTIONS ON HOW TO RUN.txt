Requirements: DOCKER



how to install docker
    1. Visit https://docs.docker.com/desktop/setup/install/windows-install/

    2. Download and install Docker Desktop.

    3. Follow the installer instructions. Enable WSL 2 if prompted.

    4. Restart your computer if required.

    5. Open Docker Desktop and wait for it to finish starting.

    IF WSL IS GETTING ERROR
        RUN 
            wsl --install or wsl --update
        
        THEN CLOSE AND OPEN DOCKER DESKTOP AND WAIT FOR IT TO FINISH STARTING
    
    HOW TO RUN

        docker compose up --build -d

    HOW TO STOP
    
        docker compose down
        

for mac:

    1. Visit https://docs.docker.com/desktop/setup/install/mac-install/

    2. Download Docker Desktop for your Mac's processor:

    Apple silicon (M-series)

    Intel

    3. Install Docker Desktop by following the instructions.

    4. Open Docker Desktop and wait for it to start.

    HOW TO RUN

        docker compose up --build -d

    HOW TO STOP
    
        docker compose down




AFTER SETUP
HOW TO RUN
docker compose up --build -d

HOW TO STOP
docker compose down
