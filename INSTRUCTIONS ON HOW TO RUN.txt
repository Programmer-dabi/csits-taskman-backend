Requirements: DOCKER



how to install docker
    Visit https://docs.docker.com/desktop/setup/install/windows-install/

    Download and install Docker Desktop.

    Follow the installer instructions. Enable WSL 2 if prompted.

    Restart your computer if required.

    Open Docker Desktop and wait for it to finish starting.

for mac:

    Visit https://docs.docker.com/desktop/setup/install/mac-install/

    Download Docker Desktop for your Mac's processor:

    Apple silicon (M-series)

    Intel

    Install Docker Desktop by following the instructions.

    Open Docker Desktop and wait for it to start.



AFTER SETUP
HOW TO RUN
docker compose up --build -d

HOW TO STOP
docker compose down
